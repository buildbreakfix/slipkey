# Slipkey Python SDK

A Python implementation of the Slipkey protocol, providing tools for client-side slip generation and server-side slip validation. Slipkey is a lightweight proof-of-work mechanism designed for rate limiting and spam prevention.

This SDK allows developers to integrate Slipkey into their Python applications easily, supporting both RSA and EdDSA cryptographic algorithms, configurable Proof-of-Work, and customizable server-side credit logic.

## Features

*   **Client and Server Classes:** `SlipkeyClient` for generating proof-of-work and client tokens, and `SlipkeyServer` for processing these tokens and managing state.
*   **RSA Key Handling:** Primary support for RSA keys, with public keys represented as JWK (JSON Web Key) in token claims and PEM for PoW string construction.
*   **EdDSA Support:** Support for EdDSA keys, currently using hex-encoded public keys in token claims and for PoW.
*   **Configurable PoW:** Client-side PoW parameters like default target score and maximum iterations can be configured.
*   **Proof-of-Work Algorithm:** Uses SHA-256 hashing with a leading-zero count for scoring.
*   **JWT-Based Tokens:** Client slips and server-issued states are JWTs.
*   **Configurable Server-Side Logic:**
    *   Server behavior (key, algorithm, default target score for validation) is configurable.
    *   Credit calculation is customizable via a user-provided function that processes `ServerCreditMetadata`.
*   **Dataclass Configuration:** Client and Server are configured using `SlipkeyClientConfig` and `SlipkeyServerConfig` dataclasses for clarity and ease of use.
*   **Key Generation Utilities:** Includes `generate_secret_key` for creating RSA and EdDSA private key objects.

## Core Concepts

*   **`block_iso_string`**: An ISO 8601 formatted timestamp string representing the target "block" or time window for which the Proof-of-Work is being generated. This ensures slips are for a current or future period.
*   **`state_jwt`**: A JWT issued by the server after validating a client's slip. This token encapsulates the client's current credit, chain length, and other stateful information. The client includes this in its next slip JWT to maintain session continuity. For the first (genesis) slip, this is `None`.
*   **`nonce`**: A random string generated by the client as part of the PoW hash input. Finding a suitable nonce that results in a hash meeting the target score is the core of the PoW.
*   **`target_score`**: An integer representing the minimum number of leading zeros required in the hex digest of the PoW hash. Higher scores are more difficult to achieve.
*   **`create` (flag)**: A boolean flag in the client slip JWT. `True` indicates a "genesis" slip (no prior `state_jwt`), `False` indicates a subsequent slip building upon a previous state.

## Configuration

Configuration for the client and server is managed through dedicated dataclasses.

### `SlipkeyClientConfig`

```python
from slipkey_sdk.slipkey import SlipkeyClientConfig

client_config = SlipkeyClientConfig(
    secret_key_input: str | object | None = None, # Raw private key (PEM string for RSA, hex for EdDSA) or key object. If None, a new key is generated.
    algorithm: str = 'RSA',              # Cryptographic algorithm ('RSA' or 'EdDSA'). Defaults to 'RSA'.
    default_target_score: int = 1,       # Default PoW target score if not specified in generate_signed_slip.
    default_max_pow_iterations: int = 1000000 # Default max PoW attempts if not specified.
)
```

### `SlipkeyServerConfig`

```python
from slipkey_sdk.slipkey import SlipkeyServerConfig, ServerCreditMetadata
from typing import Callable # For Callable type hint

server_config = SlipkeyServerConfig(
    secret_key_input: str | object | None = None, # Raw private key (PEM string for RSA, hex for EdDSA) or key object. If None, a new key is generated.
    algorithm: str = 'RSA',              # Cryptographic algorithm ('RSA' or 'EdDSA'). Defaults to 'RSA'.
    default_state_token_expiration_seconds: int = 7 * 24 * 60 * 60, # Default 7 days for server-issued state JWTs.
    custom_credit_calculator: Callable[[ServerCreditMetadata], float | int] | None = None, # Optional custom function for credit calculation.
    default_expected_target_score: int = 1 # Default score server expects client slips to meet or exceed.
)
```

## `SlipkeyClient` API

### `__init__(self, config: SlipkeyClientConfig)`
Initializes a new client instance with the provided configuration.

### `get_public_jwk() -> dict | None`
Returns the client's public key in JWK format if the algorithm is RSA. Returns `None` for EdDSA (as it uses hex serial).

### `get_public_pem() -> str | None`
Returns the client's public key in PEM format if the algorithm is RSA. Returns `None` for EdDSA.

### `generate_signed_slip(self, block_iso_string: str, state_jwt: str | None, create: bool, target_score: int | None = None, max_iterations: int | None = None) -> dict`
Performs the Proof-of-Work and generates a signed JWT (client slip token).
*   `block_iso_string`: The target block/time window.
*   `state_jwt`: The previous state JWT from the server (or `None` if `create` is `True`).
*   `create`: Boolean indicating if this is a genesis slip.
*   `target_score` (optional): Overrides `default_target_score` from config.
*   `max_iterations` (optional): Overrides `default_max_pow_iterations` from config.
*   **Returns a dictionary:**
    ```json
    {
        "slip_payload_for_jwt": {
            "publicKey": { ... }, // JWK for RSA, hex string for EdDSA
            "block": "...",       // block_iso_string used
            "nonce": "...",
            "state": "...",       // state_jwt passed in
            "create": true|false
        },
        "pow_details": {
            "score": 1,
            "hash": "0...",
            "nonce": "...",
            "iterations_taken": 12345
        },
        "token": "eyJ...", // The generated client slip JWT
        "client_public_key_pem_for_pow": "-----BEGIN PUBLIC KEY..." // PEM (RSA) or hex (EdDSA) used in PoW
    }
    ```

### `process_response(self, response: dict) -> tuple[float | int, str | None]`
Processes a response dictionary (typically from `SlipkeyServer.process_client_token`).
Currently, it primarily extracts and updates the client's internal awareness of its credit.
*   `response`: The server's response dictionary.
*   **Returns:** A tuple `(current_credit, error_message_if_any)`.

## `SlipkeyServer` API

### `__init__(self, config: SlipkeyServerConfig)`
Initializes a new server instance with the provided configuration.

### `get_public_jwk() -> dict | None`
Returns the server's public key in JWK format if its algorithm is RSA.

### `get_public_pem() -> str | None`
Returns the server's public key in PEM format if its algorithm is RSA.

### `process_client_token(self, token: str, expected_target_score: int | None = None) -> tuple[dict | None, str | None]`
Processes a client's slip JWT. It verifies the token, validates the PoW, calculates credit, and issues a new state JWT.
*   `token`: The client's slip JWT string.
*   `expected_target_score` (optional): Overrides `default_expected_target_score` from server config for this specific validation.
*   **Returns:** A tuple `(success_response_dict, error_message_str)`.
    *   If successful, `success_response_dict` contains:
        ```json
        {
            "block": "...",        // block_iso_string from client token
            "len": 1,              // New chain length for client state
            "state": "eyJ...",     // New server-issued state JWT for the client
            "score": 1,            // PoW score calculated by server
            "hash": "0...",        // PoW hash calculated by server
            "expires": 167... ,    // Expiration timestamp of the new state JWT
            "credit": 11,          // Client's new total credit
            "creditEarned": 11,    // Credit earned from this specific slip
            "is_below_target_score": false, // True if PoW score was >0 but < expected_target_score
            "publicKey": { ... } // Client's public key (JWK or hex) from their token
        }
        ```
    *   If failed, `error_message_str` contains the reason.

## Custom Credit Calculation

The server's credit awarding logic can be customized.

### `ServerCreditMetadata`
This dataclass is passed to the credit calculation function:
```python
@dataclass
class ServerCreditMetadata:
    block_timestamp: str        # ISO string of the block solved
    time_solved: datetime       # UTC datetime object of validation time
    pow_score: int              # Achieved PoW score
    chain_length: int           # New chain length for the state being issued
    client_public_key_claim_value: dict | str # Client's publicKey claim (JWK for RSA, hex for EdDSA)
    previous_credit: float | int # Credit from the previous state
    previous_chain_length: int   # Chain length from the previous state
    is_below_target_score: bool # True if score was valid (>0) but below server's expected target
```

### Example Custom Calculator
Define a function matching `Callable[[ServerCreditMetadata], float | int]` and pass it to `SlipkeyServerConfig`:
```python
from slipkey_sdk.slipkey import SlipkeyServerConfig, ServerCreditMetadata
import datetime # Required for ServerCreditMetadata type hint if used directly

def my_credit_logic(metadata: ServerCreditMetadata) -> int:
    if metadata.is_below_target_score:
        # Optionally, penalize or give less credit if score is below target but still valid
        return metadata.previous_credit # No credit change if below target

    credit_earned = metadata.pow_score * 20 # Award 20 points per PoW score unit
    if metadata.chain_length % 10 == 0: # Bonus every 10 slips
        credit_earned += 50
    return metadata.previous_credit + credit_earned

server_cfg = SlipkeyServerConfig(
    # ... other parameters ...
    custom_credit_calculator=my_credit_logic
)
# server = SlipkeyServer(config=server_cfg)
```

## Token Claim Highlights

### Client Slip JWT (sent to server)
*   `publicKey`: Client's public key. JWK object for RSA, hex string for EdDSA.
*   `block`: ISO 8601 timestamp string (target block).
*   `nonce`: PoW nonce string.
*   `state`: Previous state JWT from server (or `null`/absent if `create` is true).
*   `create`: Boolean, true for genesis slips.
*   Standard JWT claims: `iat`, `exp`.

### Server State JWT (issued to client)
*   `sub`: Client's public key used for PoW (PEM for RSA, hex for EdDSA). Used for linking state to PoW identity.
*   `publicKey`: Client's public key as sent in their token (JWK for RSA, hex for EdDSA). Used for potential re-verification or client identification.
*   `block`: ISO 8601 timestamp of the block this state is based on.
*   `len`: Chain length (number of slips processed in this sequence).
*   `credit`: Total accumulated credit for the client.
*   Standard JWT claims: `iat`, `exp`.

## Example Usage

```python
import datetime
import json # For pretty printing
from slipkey_sdk.slipkey import (
    SlipkeyClient, SlipkeyServer,
    SlipkeyClientConfig, SlipkeyServerConfig,
    generate_secret_key, ServerCreditMetadata # Make sure ServerCreditMetadata is available for type hints
)

# --- Configuration ---
client_alg = 'RSA' # Try 'EdDSA' as well
# Generate key objects directly
client_private_key_obj = generate_secret_key(algorithm=client_alg)
server_private_key_obj = generate_secret_key(algorithm=client_alg) # Can be different

client_config = SlipkeyClientConfig(
    secret_key_input=client_private_key_obj, # Pass the key object
    algorithm=client_alg,
    default_target_score=1 # Client aims for at least 1
)
client = SlipkeyClient(config=client_config)
print(f"Client Public Key (PEM for RSA, Hex for EdDSA):\n{client.get_public_pem() or client.public_key_serial}")

# Example of a custom credit calculator for the server
def simple_credit_calc(metadata: ServerCreditMetadata) -> int:
    print(f"[CustomCreditCalc] Metadata received: score={metadata.pow_score}, below_target={metadata.is_below_target_score}, prev_credit={metadata.previous_credit}")
    if metadata.is_below_target_score:
        return metadata.previous_credit # No new credit if below server's expected target
    # Award 100 points per score unit, plus 10 per chain length unit
    return metadata.previous_credit + (metadata.pow_score * 100) + (metadata.chain_length * 10)

server_config = SlipkeyServerConfig(
    secret_key_input=server_private_key_obj, # Pass the key object
    algorithm=client_alg,
    default_expected_target_score=2, # Server expects a score of at least 2
    custom_credit_calculator=simple_credit_calc
)
server = SlipkeyServer(config=server_config)
print(f"Server Public Key (PEM for RSA, Hex for EdDSA):\n{server.get_public_pem() or server.public_key_serial}")


# --- Client Generates First Slip (Genesis) ---
print("\nClient: Generating genesis slip...")
# Target a block timestamp slightly in the future
block_time_iso = (datetime.datetime.now(datetime.timezone.utc) + datetime.timedelta(seconds=30)).isoformat()

current_client_state_jwt = None # No state for genesis slip
is_genesis = True

try:
    signed_slip_result = client.generate_signed_slip(
        block_iso_string=block_time_iso,
        state_jwt=current_client_state_jwt,
        create=is_genesis,
        target_score=client_config.default_target_score
        # max_iterations can be passed if needed, else uses config default
    )
    client_jwt_to_server = signed_slip_result['token']
    print(f"Client: Token: {client_jwt_to_server[:40]}...")
    print(f"Client: PoW Details: Score={signed_slip_result['pow_details']['score']}, Iterations={signed_slip_result['pow_details']['iterations_taken']}")

    # --- Server Processes Client Token ---
    print("\nServer: Processing client token...")
    # Server can specify an expected_target_score different from its default if desired, e.g. for specific endpoints
    server_response_data, error_msg = server.process_client_token(client_jwt_to_server)

    if error_msg:
        print(f"Server: Error processing token: {error_msg}")
    else:
        print("Server: Token processed successfully!")
        print(f"  Server Response (pretty): {json.dumps(server_response_data, indent=2)}")

        # Client processes server response
        client_credit, client_proc_error = client.process_response(server_response_data)
        if client_proc_error:
             print(f"Client: Error processing server response: {client_proc_error}")
        else:
            print(f"Client: Current Credit: {client_credit}")
            current_client_state_jwt = server_response_data.get('state') # Update for next request
            is_genesis = False # Next slip will not be genesis

            # --- Client Generates Subsequent Slip (with state) ---
            if current_client_state_jwt:
                print("\nClient: Generating subsequent slip with state...")
                block_time_2_iso = (datetime.datetime.now(datetime.timezone.utc) + datetime.timedelta(seconds=60)).isoformat()

                signed_slip_result_2 = client.generate_signed_slip(
                    block_iso_string=block_time_2_iso,
                    state_jwt=current_client_state_jwt,
                    create=is_genesis,
                    target_score=client_config.default_target_score + 1 # e.g. try for a higher score
                )
                client_jwt_2_to_server = signed_slip_result_2['token']
                print(f"Client: Token 2: {client_jwt_2_to_server[:40]}...")
                print(f"Client: PoW Details 2: Score={signed_slip_result_2['pow_details']['score']}, Iterations={signed_slip_result_2['pow_details']['iterations_taken']}")

                print("\nServer: Processing client token 2...")
                server_response_data_2, error_msg_2 = server.process_client_token(client_jwt_2_to_server)
                if error_msg_2:
                    print(f"Server: Error processing token 2: {error_msg_2}")
                else:
                    print("Server: Token 2 processed successfully!")
                    print(f"  Server Response 2 (pretty): {json.dumps(server_response_data_2, indent=2)}")
                    client_credit_2, _ = client.process_response(server_response_data_2)
                    print(f"Client: Current Credit after 2nd slip: {client_credit_2}")


except Exception as e:
    print(f"An error occurred: {e}")

```
